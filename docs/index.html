This will install a Battery Emulator factory image onto your device, over USB, through a web browser supporting WebSerial.

Step 1: Attach your device (optionally holding down BOOT button)

Plug in your supported board to your computer using a USB cable.

Some devices require you to hold down the BOOT button during the following steps. If your device has no BOOT button, connect GND and GPIO0 together instead.

You can release BOOT once the device has started erasing/installing.

Step 3: Install!

Click the button below, and find your device's serial interface. Select 'Erase device' when asked.

The board configuration is written together with the firmware, and replaces any configuration already stored on the board. The emulator starts up configured for that board; the Hardware configuration page of its web interface shows what it loaded.

Step 4: Configure WiFi

Your device will boot as an access point with a "battery-emulator-..." SSID.

  1. Connect to it over Wi-Fi, the factory-default password: 123456789
  2. Access the web interface at http://192.168.4.1/ address in your web browser
  3. Visit the Settings page, and update the network config with your local network WiFi SSID and password
  4. Go back to the main page and Reboot
  5. Access it over your local WiFi network IP address
  6. Change the default AP password to something more secure. When the AP is running with the factory-default password, it is automatically disabled after 5 minutes.
